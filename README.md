# Bedrock Launcher (Android)

Интерфейс лаунчера лежит в `app/src/main/assets/index.html` и показывается в WebView.
Запуск игры и проверка версии идут через Kotlin (`MainActivity.kt`, мост `Android`).

## Как собрать
1. Установи Android Studio (последнюю стабильную).
2. File -> Open -> выбери папку `BedrockLauncher`. Дождись синхронизации Gradle.
3. Подключи телефон (отладка по USB) или запусти эмулятор и нажми Run.
   Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`
   (Build -> Build Bundle(s) / APK(s) -> Build APK(s)).

## Что уже работает
- Кнопка «Играть» запускает установленный Minecraft Bedrock (`com.mojang.minecraftpe`).
- На карточке версии показывается версия установленной игры.
- Выбор PNG для скина, рисование скина, слоты, темы, кнопка «Назад».
- Ссылка «Моды» открывается в браузере.
